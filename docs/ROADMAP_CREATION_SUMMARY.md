## 🎯 Как использовать

### Для AI-агентов

#### Первый раз (изучение)

1. Открой **README.md** - навигационный центр
2. Прочитай разделы:
   - "Обзор документов"
   - "Как начать работу"
   - "Структура методологии"
3. Изучи примеры:
   - `docs/roadmap.md` - активный roadmap
   - `docs/tasklists/tasklist-s0.md` - пример тасклиста
   - `docs/tasklists/tasklist-techdebt-s0.md` - пример TechDebt

#### Во время работы (создание спринтов)

**Задача:** Создать новый спринт

1. Открой `docs/roadmap.md`
2. Добавь новую строку в таблицу спринтов:

```markdown
| **S{N}** | {Название} | 💡 Идея | {Цель одним предложением} |
• {Высокоуровневая работа 1}<br>
• {Высокоуровневая работа 2}<br>
• {Высокоуровневая работа 3} | TBD |
```

3. Создай файл `docs/tasklists/tasklist-s{N}.md`
4. Разбей каждую работу на итерации (1-3 дня)
5. Обнови статус спринта: 💡 → 📋
6. Обнови ссылку на тасклист в roadmap

**Задача:** Выполнить итерацию

1. Открой `docs/tasklists/tasklist-s{N}.md`
2. Найди первую итерацию со статусом 🔲 TODO
3. Обнови статус: 🔲 → 🔄 IN PROGRESS
4. Выполни все задачи из чек-листа
5. Проверь Definition of Done (11 пунктов)
6. Обнови статус: 🔄 → ✅ DONE + дата

### Для разработчиков

1. Открой **GETTING_STARTED_RU.md** - быстрый старт на русском
2. Изучи структуру (3 уровня планирования)
3. Посмотри примеры (roadmap.md, tasklists/)
4. Используй для планирования своих задач

## 📊 Структура методологии (кратко)

```
УРОВЕНЬ 1: ROADMAP (roadmap.md)
│
│  Описание: ЧТО делаем (бизнес-цели)

│
├── Спринт S0: MVP (✅ Завершен)
├── Спринт S1: Персистентное хранение (📋 Запланирован)
│   │
│   └── УРОВЕНЬ 2: TASKLIST (tasklist-s1.md)
│       │
│       │  Описание: КАК делаем (итерации)
│       │  Детализация: Средняя (конкретные шаги)
│       │  Пример: "Создать модель User"
│       │
│       ├── Iteration 1: Анализ требований (🔲 TODO)
│       │   │
│       │   └── УРОВЕНЬ 3: TASKS (чек-лист)
│       │       │
│       │       │  Описание: ШАГ за ШАГОМ (действия)
│       │       │  Детализация: Низкая
│       │       │  Пример: "Создать файл models/user.py"
│       │       │
│       │       - [ ] Создать файл models/user.py
│       │       - [ ] Добавить поле id
│       │       - [ ] Добавить поле email
│       │       - [ ] Написать тесты
│       │
│       ├── Iteration 2: Реализация моделей (🔲 TODO)
│       └── Iteration 3: Миграции БД (🔲 TODO)
│
└── Спринт S2: Production Ready (💡 Идея)
```

## 🔄 Жизненный цикл спринта

```
1. 💡 Идея
   │
   ├─→ В roadmap.md добавлена строка
   │   Статус: 💡 Идея
   │   Состав работ: высокий уровень
   │
   ↓ Детализация

2. 📋 Запланирован
   │
   ├─→ Создан tasklist-sN.md
   │   Итерации: 3-10 штук
   │   Каждая: 1-3 дня
   │
   ↓ Начало работы

3. 🔄 В работе
   │
   ├─→ Итерации выполняются:
   │   Iter 1: 🔲 → 🔄 → ✅
   │   Iter 2: 🔲 → 🔄 → ✅
   │   Iter 3: 🔲 → 🔄 → ✅
   │
   ↓ Все итерации завершены

4. ✅ Завершен
   │
   ├─→ В roadmap.md обновлен статус
   │   Метрики собраны
   │   Результаты зафиксированы
   │
   ↓ Анализ

5. 📊 Ретроспектива
   │
   └─→ Выводы, улучшения для следующего спринта
```

## ✅ Принципы (главное)

### 1. Три уровня абстракции

| Уровень | Что | Детализация | Пример |
|---------|-----|-------------|--------|
| **ROADMAP** | ЧТО делаем | Высокая | "Реализовать аутентификацию" |
| **TASKLIST** | КАК делаем | Средняя | "Создать модель User" |
| **TASKS** | ШАГИ | Низкая | "Создать файл models/user.py" |

### 2. Размер работ

| Единица | Длительность | Количество |
|---------|--------------|------------|
| **Задача** | 15-60 мин | 1 действие |
| **Итерация** | 1-3 дня | 5-15 задач |
| **Спринт** | 1-4 недели | 3-10 итераций |

### 3. Статусы

**Спринты:**
- 💡 Идея - концепция сформулирована
- 📋 Запланирован - tasklist создан
- 🔄 В работе - итерации выполняются
- ✅ Завершен - все итерации выполнены

**Итерации:**
- 🔲 TODO - не начата
- 🔄 IN PROGRESS - в работе
- ✅ DONE - выполнена
- ❌ BLOCKED - заблокирована

### 4. Definition of Done (11 пунктов)

Итерация считается завершенной, если:

1. ✅ Код написан
2. ✅ Type hints везде
3. ✅ Docstrings на русском
4. ✅ Logging (не print)
5. ✅ DRY - нет дублирования
6. ✅ Методы < 40 строк
7. ✅ Тесты написаны
8. ✅ `make test` проходит
9. ✅ `make lint` проходит
10. ✅ Критерий готовности выполнен
11. ✅ Ручное тестирование

## 🎓 Частые вопросы

**Q: С чего начать?**
A: Открой `docs/roadmap_templates/README.md` - навигационный центр со всей информацией.

**Q: Как создать новый спринт?**
A:
1. Добавь строку в `docs/roadmap.md` (статус 💡)
2. Создай `docs/tasklists/tasklist-sN.md` с итерациями
3. Обнови статус спринта: 💡 → 📋

**Q: Сколько итераций должно быть в спринте?**
A: Обычно 3-10 итераций. Если больше 10 → разбей на 2 спринта.

**Q: Сколько длится итерация?**
A: 1-3 дня. Если больше → разбей на меньшие.

**Q: Где взять шаблоны?**
A: В README.md есть описания. Также смотри примеры:
- `docs/roadmap.md`
- `docs/tasklists/tasklist-s0.md`

**Q: Нужно ли создавать полные файлы шаблонов?**
A: Не обязательно на данном этапе. README.md содержит всю необходимую информацию. Полные файлы (ROADMAP_TEMPLATE.md, ROADMAP_QUICK_REFERENCE.md, ROADMAP_PRACTICAL_GUIDE.md) можно создать позже при необходимости.
