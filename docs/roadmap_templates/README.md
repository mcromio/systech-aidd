## 🚀 Как начать работу

### Для AI-агента (первый раз)

```
Шаг 1: Прочитать ROADMAP_TEMPLATE.md (полное понимание)
        ↓
Шаг 2: Добавить в закладки ROADMAP_QUICK_REFERENCE.md (быстрый доступ)
        ↓
Шаг 3: Открыть ROADMAP_PRACTICAL_GUIDE.md (копировать шаблоны)
        ↓
Шаг 4: Начать работу с активным roadmap.md
```

### Для AI-агента (последующая работа)

```
Задача: "Создать новый спринт"
  ↓
Открыть: ROADMAP_PRACTICAL_GUIDE.md → "Шаблон новой строки в roadmap"
  ↓
Скопировать и заполнить шаблон
  ↓
Проверить по чек-листу в ROADMAP_QUICK_REFERENCE.md
```

```
Задача: "Выполнить итерацию"
  ↓
Открыть: tasklists/tasklist-sN.md
  ↓
Следовать чек-листу из ROADMAP_QUICK_REFERENCE.md → "Выполнение итерации"
  ↓
Проверить Definition of Done (11 пунктов)
```

## 💡 Частые вопросы

### Q: Какой документ читать первым?

**A:** Зависит от цели:
- **Изучение методологии** → ROADMAP_TEMPLATE.md (полностью)
- **Создать спринт сейчас** → ROADMAP_PRACTICAL_GUIDE.md (шаблоны)
- **Проверить формат** → ROADMAP_QUICK_REFERENCE.md (справка)

### Q: Нужно ли читать все три документа?

**A:**
- **AI-агент:** Да, для полного понимания процесса
- **Разработчик:** QUICK_REFERENCE достаточно для работы
- **Руководитель:** TEMPLATE для понимания структуры

### Q: Когда обновлять шаблоны?

**A:**
- **TEMPLATE:** При изменении методологии (редко)
- **QUICK_REFERENCE:** При добавлении новых правил (периодически)
- **PRACTICAL:** При появлении новых типовых кейсов (часто)

### Q: Можно ли изменять шаблоны под проект?

**A:** Да, шаблоны - это отправная точка. Адаптируйте под:
- Специфику домена
- Размер команды
- Технологический стек
- Методологию разработки

## 🎓 Методология в кратце

### Три уровня планирования

```
ROADMAP (roadmap.md)
  └─ Спринт S1: "Аутентификация" (💡 → 📋 → 🔄 → ✅)
       └─ TASKLIST (tasklists/tasklist-s1.md)
            ├─ Iteration 1: "Модели User" (🔲 → 🔄 → ✅)
            ├─ Iteration 2: "API регистрации" (🔲 → 🔄 → ✅)
            └─ Iteration 3: "JWT токены" (🔲 → 🔄 → ✅)
```

### Принцип разделения

| Уровень | Что описываем | Детализация |
|---------|---------------|-------------|
| **ROADMAP** | ЧТО делаем (бизнес-цель) | Высокая (без деталей) |
| **TASKLIST** | КАК делаем (итерации) | Средняя (конкретные шаги) |
| **TASKS** | ШАГ за ШАГОМ (чек-лист) | Низкая (действия) |
