## 📊 Структура методологии

```
Уровень 1: ROADMAP (roadmap.md)
├── Спринт S0: MVP ✅
├── Спринт S1: Персистентное хранение 📋
│   └── Уровень 2: TASKLIST (tasklists/tasklist-s1.md)
│       ├── Iteration 1 🔲
│       ├── Iteration 2 🔲
│       └── Iteration 3 🔲
└── Спринт S2: Production Ready 💡
    └── (требует детализации)

Легенда статусов:
💡 Идея - концепция сформулирована
📋 Запланирован - tasklist создан
🔄 В работе - итерации выполняются
✅ Завершен - все итерации выполнены
🔲 TODO - итерация не начата
```

## 📝 Принципы использования

### Для AI-агентов

1. **Всегда начинать с roadmap.md** - добавить спринт (💡 Идея)
2. **Детализировать в tasklist** - разбить на итерации (📋 Запланирован)
3. **Выполнять итерации последовательно** - 🔲 → 🔄 → ✅
4. **Обновлять статусы сразу** - прозрачность прогресса
5. **Проверять Definition of Done** - 11 пунктов для каждой итерации

### Уровни абстракции

| Уровень | Что описываем | Пример |
|---------|---------------|--------|
| **Roadmap** | ЧТО делаем (бизнес-цель) | "Реализовать аутентификацию" |
| **Tasklist** | КАК делаем (итерации) | "Создать модель User", "API регистрации" |
| **Tasks** | ШАГИ (действия) | "Создать файл models/user.py" |
